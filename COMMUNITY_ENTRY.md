# Community entry strategy

Prepared 12 Sep 2026.

## 1. AI Stack Devs / AI Town community

AI Town's official repository links directly to the AI Stack Devs Discord. This is the closest existing builder community because its members are already working on persistent simulated-agent worlds.

Entry angle: experimental design, not promotion.

Lead with the preserved baseline and ask one concrete question about causal memory or acquired skill. Do not ask for stars.

Reference: https://github.com/a16z-infra/ai-town

## 2. Reddit technical AI communities

Recent posts show that persistent-world and persistent-RPG agent systems are actively discussed. Engagement varies sharply: a concrete playable persistent LLM RPG attracted substantial attention, while more abstract 'world-driven agent' discussion attracted far less.

Practical implication: a persistent-world concept by itself is not enough. Show a tangible artifact, inspectable trace or runnable/observable experience.

Candidate communities:

- r/LocalLLaMA
- r/OpenSourceAI
- adjacent agent / artificial-life communities where self-promotion rules permit it

Entry angle: 'here is the preserved baseline and the experiment we are about to run', with one authentic artifact and one falsifiable question.

## 3. Hacker News

Do **not** submit as Show HN yet.

The current Show HN guidelines say the submission should be something people can actually try, ideally without signup or other barriers. A documentation-only repository is not enough for a strong Show HN.

Gate before Show HN:

- sanitized public Observer demo or interactive read-only view;
- no access token or credential barrier;
- clear README and evidence already in place;
- creator available to answer technical questions.

Guidelines: https://news.ycombinator.com/showhn.html

## 4. Research-facing audience

After the LLM phase produces enough longitudinal data, write a technical comparison between:

- deterministic baseline;
- LLM policy;
- causal-memory traces;
- skill acquisition tests;
- spatial-model changes;
- failure and null results.

The strongest research story is not 'six AI beings became alive'. It is 'we preserved a baseline before changing the policy, then tested which changes are actually attributable to biography, skill and spatial causality.'
