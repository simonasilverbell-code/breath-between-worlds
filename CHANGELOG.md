# Changelog

## Public baseline showcase — 12 Sep 2026

This is the first public documentation snapshot for Breath Between Worlds, codename LUMEN.

Published in this phase:

- a documentation-first public repository separated from the private implementation;
- a dated provenance record with SHA-256 fingerprints for the preserved private snapshot;
- verified baseline event counts and selected event examples;
- authentic artifact exports tied to model ticks and event IDs;
- a public read-only Observer Snapshot;
- the first falsifiable post-baseline experiment proposal on biography-conditioned choice;
- an open research-feedback issue;
- related-work positioning and explicit limitations;
- rights, contribution, security and privacy boundaries.

The preserved checkpoint documented by this public baseline contains 6 residents, 56 model-hours and 701 journaled events. It uses the deterministic autonomous control baseline and is not presented as evidence of consciousness or spontaneous culture.
