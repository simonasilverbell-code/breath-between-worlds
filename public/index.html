VERIFIED BASELINE

Refusal is an action

Four explicit refusals are stored as refusal events instead of silently becoming cooperation.

Physical outcomes differ

A reed construction collapsed at tick 23. A later, smaller construction stood at tick 26. This is not yet claimed as learned skill.

Private → voluntary public

Iv measured soil moisture at 0.27 and later chose to publish that observation into the shared library.

Artifacts have structure

Drawings are stored as strokes and colors. Music is stored as pitch and duration sequences.

DESIGN PRINCIPLE

We created the conditions. We did not decide who they should become.

The baseline deliberately avoids money, rankings, assigned professions, mandatory productivity and a single resident success score.

WHAT THIS DOES NOT PROVE

No consciousness claim.

The preserved public-evidence checkpoint uses a deterministic autonomous control policy. It is a baseline for persistence, memory boundaries, causal continuity and artifact recording, not proof of consciousness or spontaneous culture.

NEXT EXPERIMENT

Does biography change a later choice?

We plan a controlled comparison where one relevant autobiographical memory is present in one branch and withheld or altered in another, while the rest of the state is matched as closely as possible.
