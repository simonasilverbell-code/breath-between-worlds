# Contributing and research feedback

Breath Between Worlds is currently published as a documentation-first research showcase, not as an open-source code release.

The most useful contributions at this stage are **critique, experimental-design suggestions, falsifiable tests, and references to related work**.

Good questions include:

- How would you test whether a later action was genuinely conditioned by earlier personal experience?
- What evidence would distinguish acquired skill from a fixed action policy selecting a better option?
- How should local perception and social information provenance be audited?
- Which spatial constraints are necessary before calling the world meaningfully embodied rather than 2D/2.5D?
- What failure cases should be published alongside successful-looking behavior?

Please use GitHub Issues for research discussion. The private implementation, canonical database and full resident-memory contents are not currently open for code contributions.
