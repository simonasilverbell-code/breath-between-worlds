# Observer snapshot

The private Observer is a read-only projection of world state. Browsing it does not advance simulation time and is not fed back into resident decisions.

A public **sanitized Observer Snapshot** is now available at:

https://breath-between-worlds.onrender.com/observer.html

It is intentionally not connected to the private live world. The public page is built only from the preserved evidence subset and exposes no observer token, operational credentials, canonical database, control action, or resident-private memory.

The public snapshot currently lets a visitor:

- filter selected verified events by resident;
- inspect explicit refusal events;
- inspect a collapsed-versus-standing construction outcome;
- inspect the first voluntary shared-library publication sequence;
- view the earliest stored drawing rendered from exact saved stroke coordinates;
- synthesize Ori's earliest stored music phrase directly from its preserved pitch/duration sequence.

The original private Observer additionally contains map state, resident histories, project traces, environmental state, created objects and broader artifact history. Those views are not exposed publicly until their privacy boundaries are reviewed.

What matters experimentally is that the interface can be used to inspect a resident's history and the world record without becoming the director of that history.
