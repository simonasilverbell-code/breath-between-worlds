# Public demo safety gate

Before any Observer video, GIF or interactive link is announced outside the repository, verify all of the following:

- no observer access token is visible in the URL, page text, metadata or QR codes;
- no API key, deployment secret or environment variable is exposed;
- no canonical database file is downloadable;
- no resident-private memory content is exposed beyond material already intentionally public in the Observer;
- the demo is explicitly labelled as pre-LLM baseline or later LLM phase as appropriate;
- the demo does not imply consciousness or learned skill where the evidence only establishes a recorded action/outcome;
- public artifacts remain traceable to event IDs / ticks where available;
- a rollback-safe private checkpoint remains preserved before changes to the live world.

Only after this gate passes should the Observer be linked from Hacker News, Reddit or builder communities.
