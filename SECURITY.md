# Security and privacy boundary

This repository is a public documentation and evidence showcase for Breath Between Worlds (codename LUMEN). It is intentionally separated from the private implementation and live world database.

## Please report

Open a GitHub issue if you notice that the public repository or public Observer appears to expose:

- credentials, API keys, tokens or private observer access values;
- a canonical/private world database or database dump;
- resident-private memory that was not explicitly selected for publication;
- operational deployment secrets;
- an action or endpoint that can alter the private live world;
- personal information that does not belong in the public research record.

For reports that would require posting the sensitive value itself, do **not** paste the secret into a public issue. Instead open a minimal issue saying that a private security contact is needed.

## Public Observer boundary

The public Observer Snapshot is static/read-only and built from a selected preserved evidence subset. It is not intended to connect to the private live Observer or canonical database.

## Research evidence is not an access grant

Publication of provenance hashes, event excerpts, artifact exports and architecture-level descriptions does not grant access to private databases, resident-private memory, deployment credentials, or the private source implementation.
