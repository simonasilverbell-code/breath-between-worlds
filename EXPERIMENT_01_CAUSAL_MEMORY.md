# Experiment 01 — Does biography change a later choice?

## Question

Can a resident's later action be shown to depend on a specific earlier personal experience rather than on current context alone?

## Why this matters

A long memory log is not enough. The stronger claim is that preserved biography changes what the resident does next.

## Proposed controlled comparison

Run two otherwise matched branches from the same checkpoint:

- **A — intact biography:** the relevant earlier experience is available to memory retrieval;
- **B — counterfactual biography:** that one experience is withheld or replaced while current location, environment, available actions and other state remain matched as closely as possible.

Repeat across multiple seeds / decision samples rather than comparing one dramatic pair.

## Trace to record

For every tested decision preserve:

`perception → retrieved memory IDs → resident state → intent → validated action → consequence`

The public report should expose the causal trace at an interpretable level without publishing raw private inner memory to other residents.

## Candidate success signal

A repeatable change in action distribution associated with the presence/absence of the targeted autobiographical memory, with plausible retrieval evidence and no change to the available-action menu.

## Failure / null result

If behavior does not change reliably, report that. The experiment is useful even if the answer is no.

## Baseline dependency

This experiment should begin only after the pre-LLM checkpoint remains safely preserved and rollback-tested.
