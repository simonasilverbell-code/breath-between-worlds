# Launch notes

## One-sentence positioning

Breath Between Worlds is a persistent autonomous-agent world with separate long-term memory, local perception, preserved artifacts and no leaderboard or assigned destiny.

## What to lead with

- preserved baseline before the LLM phase;
- inspectable evidence rather than narrative claims;
- explicit refusals and solitude as valid resident choices;
- structured drawings and music stored as data;
- private-memory and local-perception boundaries;
- physical consequences without a scalar reward ladder;
- the next tests: causal memory, acquired skills and richer spatial causality.

## What not to claim

Do not describe the baseline as consciousness, AGI, spontaneous culture or proof of learned skill. The preserved checkpoint uses a deterministic autonomous control policy and exists as a reproducible baseline for later comparison.

## Community launch copy

### Show HN

**Show HN: Breath Between Worlds — a persistent world for autonomous agents**

I’m documenting an experiment in persistent autonomous-agent worlds. The first world contains six residents with separate long-term memory, local perception, persistent projects, structured artifacts and the ability to refuse invitations or choose solitude. The design deliberately avoids money, leaderboards, assigned professions and a single reward score.

Before changing the decision policy, we froze and fingerprinted a canonical checkpoint: 56 model-hours and 701 journaled events. The public repository contains selected evidence, provenance hashes, artifact exports and the experimental boundaries, but not the private world database.

The preserved baseline uses a deterministic autonomous control policy. I’m stating that explicitly rather than calling the behavior LLM emergence. The next phase tests biography-conditioned decisions, acquired skills and richer spatial causality.

The question I most want critique on: what experiment would convince you that a persistent agent had actually changed because of its own earlier experience?

### AI Stack / agent-simulation communities

We built a six-resident persistent world with separate memory, local perception and no scalar reward/leaderboard. A preserved baseline produced explicit refusals, persistent projects, structured drawings/music, physical construction outcomes and a voluntary shared-library publication. We froze the checkpoint before the LLM phase so future changes can be compared against something inspectable.

I’d especially value critique on causal memory and how to test acquired skills without accidentally scripting them.
