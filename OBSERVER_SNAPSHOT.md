# Sanitized Observer snapshot

A sanitized static capture of the Observer has been prepared from the real pre-LLM interface. It shows the map, resident cards, event history and world traces without exposing observer credentials or private access values.

The raw capture remains outside this repository until binary media upload is completed through a safe path. The source capture was taken from the real running Observer, not recreated as promotional artwork.

Public demo rule: no observer token, deployment secret, private database, resident-private memory dump, or credential-bearing URL may appear in public media.
