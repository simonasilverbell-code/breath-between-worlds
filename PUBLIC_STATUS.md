# Public status

## Phase 0 — preserved baseline

Status: **complete and fingerprinted**.

The preserved baseline predates the LLM decision phase and is intentionally kept as a control condition. It contains six residents, 56 model-hours and 701 journaled events.

Decision policy: deterministic autonomous control policy.

Purpose: validate persistence, memory boundaries, local perception, action validation, project continuity, refusal, social provenance and structured artifacts.

## Phase 1 — LLM decision policy

Status: **planned, not yet part of the published baseline evidence**.

Requirements before first controlled run:

- rollback-safe pre-LLM checkpoint;
- causal trace capture;
- strict privacy boundaries between residents;
- explicit distinction between model decision and environment validation;
- no silent fallback to the deterministic policy after invalid model output;
- comparison against the preserved baseline.

## Phase 2 — richer spatial causality

Status: **planned**.

Goal: move beyond a mostly flat grid by making elevation, visibility, occlusion, enclosure, depth, traversability and sound propagation causally relevant.

This is not a graphics upgrade. It is an environment-model upgrade.

## Phase 3 — acquired skills and longitudinal evaluation

Status: **planned**.

Goal: test whether experience changes future practical capability and decision distributions over time.

Public reports will distinguish verified outcomes from interpretation and will include null results when a proposed effect is not supported.
