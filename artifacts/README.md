# Authentic baseline artifacts

These files are direct structured exports or deterministic renders from the preserved pre-public LUMEN checkpoint. They are included so the public record contains inspectable evidence, not only screenshots or retrospective narrative.

## Included

- [`first_drawing_sol_tick_06.svg`](first_drawing_sol_tick_06.svg) — the earliest preserved drawing event in the checkpoint, by **Соль (Sol)** at tick 6. The SVG uses the stored stroke coordinates and colors.
- [`first_music_ori_tick_04.json`](first_music_ori_tick_04.json) — the earliest preserved music event in the checkpoint, by **Ори (Ori)** at tick 4. It contains the stored pitch and duration sequence.
- [`first_library_publication_iv_tick_50.json`](first_library_publication_iv_tick_50.json) — the first voluntary shared-library publication, by **Ив (Iv)** at tick 50.
- [`evidence_manifest.json`](evidence_manifest.json) — a compact manifest tying the selected artifacts to their event ids and checkpoint chronology.

## Important distinction

The SVG is a deterministic rendering of stored drawing strokes. The music JSON is the stored musical sequence itself, not a later composition. Audio rendering can be reproduced from the note sequence using the observer's frequency mapping described in the file.

These exports do not expose the private world database or complete resident memories.
